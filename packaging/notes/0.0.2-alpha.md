Second alpha: Ubuntu and Debian packages, a self-contained window for any x86_64 Linux,
and a day of fixes from using it.

**Install**

```bash
# Fedora 44
sudo dnf install https://github.com/JasonDictos/my-claude/releases/download/v0.0.2-alpha/my-claude-0.0.2-0.1.alpha.fc44.x86_64.rpm
# Ubuntu 26.04 / Debian
curl -LO https://github.com/JasonDictos/my-claude/releases/download/v0.0.2-alpha/my-claude_0.0.2-alpha_amd64.deb
sudo apt install ./my-claude_0.0.2-alpha_amd64.deb
```

You also need [Claude Code](https://docs.anthropic.com/claude-code) (`claude`) on PATH.
On any other x86_64 Linux: the source install (`install.sh`, see the README) and, for the
window, `mc-term-0.0.2-alpha-x86_64-linux` below (one static binary; put it on PATH as `mc-term`).

**New**
- Every machine in one window: Connect a machine you can ssh to and its projects sit
  beside yours, in a section of their own; New project can create one there;
  `my-claude deploy` puts my-claude on a machine.
- The list: sections per machine, console and docker icons, F2 renames anything, a live
  preview on hover, a toolbar, and an overview of every terminal (Meta+Shift+W).
- Dropdown mode (Guake style), Undelete across machines, Add repos from your
  organisation's repos (private ones too, with a GitHub token in Settings).

**Fixed**
- Works with tmux 3.6 (Ubuntu): `up` failed there outright.
- `install.sh` works on a fresh machine (it needed unzip and a new shell).
- `up` works on a machine that is a container (devcontainers, Codespaces).
- The ssh gate: allowed keys can no longer forward sockets, and the window's own
  commands get through (sshd and the daemon's endpoint).
- A conversation open in another Claude is offered for take over, and adding a repo
  takes it over; one folder belongs to one project.
- Dialogs from another machine get their answers; the window never blocks on I/O.
