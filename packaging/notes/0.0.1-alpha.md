The first release: an alpha. It works day to day for its author; expect rough edges.

**Install (Fedora, x86_64):**

```bash
sudo dnf install https://github.com/JasonDictos/my-claude/releases/download/v0.0.1-alpha/my-claude-0.0.1-0.1.alpha.fc44.x86_64.rpm
my-claude            # the menu, in a terminal
my-claude gui        # or the window: "my-claude" in the application menu, under Development
```

You also need [Claude Code](https://docs.anthropic.com/claude-code) (`claude`) on PATH.
The package brings tmux, git, Qt 6 and qtermwidget. Your projects live in
`~/.local/share/my-claude`, your settings in `~/.config/my-claude`.

**What's in it**

- Projects: a goal and a set of repos, one long-lived Claude Code session per repo,
  resumed on the same conversation after a crash or a reboot.
- The terminal UI: one tiled tmux session per project, a side panel, a status bar
  of projects and peers.
- The native window (`mc-term`): a tab per project, a pane per repo, four on screen
  with the rest a key away, a project tree, real terminals with unlimited scrollback on
  disk, project colours, optional transparency.
- Peers that talk: projects join a claude-peers group; you can join the chat.
- From another machine: `my-claude gui --remote you@host` over ssh, with
  `my-claude remote allow <key>` on the server.
- Profiles: how your repos start (containers, dev shells) in a file of your own.

**Known**

- Fedora on x86_64 only, for now.
- The window is CPU-rendered (QTermWidget); fast enough in practice, not GPU-accelerated.
